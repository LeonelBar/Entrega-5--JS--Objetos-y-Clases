# 🎮 Super-Arcade - Simulador de Tienda de Videojuegos (Pre-Entrega 5)

Simulador interactivo desarrollado en JavaScript puro que implementa **Programación Orientada a Objetos (POO)** mediante el uso de Clases en ES6, arrays, métodos de instancia y estructuras de control.

## 🚀 Características (Pre-Entrega 5)
- **Clase ES6 (`Juego`):** Modela los productos de la tienda con propiedades esenciales (`id`, `name`, `price`, `stock`) y métodos de instancia (`venderUnidad`).
- **Instanciación:** Creación de múltiples objetos reales utilizando el operador `new`.
- **Control de Flujo y Modularización:** Menú interactivo mediante bucles `while`, condicionales y funciones de flecha para gestionar el carrito y aplicar descuentos.

## 💻 ¿Cómo ejecutar el proyecto?
1. Clona o descarga este repositorio.
2. Abre el archivo `index.html` en tu navegador web.
3. Abre la **Consola de Desarrollador** (`F12`) para ver los reportes detallados del stock y las interacciones.
